# Codemagic build speed benchmarks

Open benchmarks of build times on Codemagic. Each benchmark run has its own folder with the method, the
workflows, the app references and the raw data, so you can repeat it.

| Benchmark | Contents |
|---|---|
| [`2026-11-apple-silicon`](2026-11-apple-silicon) | Mac mini M2, Mac mini M4, Mac mini M4 Pro and Mac Studio M4 Max on XcodeBenchmark, Signal iOS and Expensify. Results page: `docs/index.html` |
| [`2025-benchmarks`](2025-benchmarks) | Earlier iOS, Android and cross-provider benchmarks (September 2025) |

Want to try the Mac Studio M4 Max or the Linux X4 machines? Use the [contact form](https://codemagic.io/contact/).
